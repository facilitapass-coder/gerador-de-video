# Logo

Copie o logo **"Laranja Principal"** (horizontal, símbolo e texto na mesma linha) do Drive
("ID - Facilita Pass Lazer") para `marca/logo/laranja-principal.png`.

Se o PNG vier com fundo preto ou canal alfa com problema, rode:

    facilita logo-corrigir

A versão corrigida vai para `marca/derivados/laranja-principal-alfa.png` e passa a ser usada
automaticamente. O arquivo original nunca é alterado.
